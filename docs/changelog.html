Vanta changelog

Changelog

Every Vanta release for Windows and macOS. Windows releases update in-app with the Update button; Mac releases end in -mac.

Saved copy. The live list from GitHub Releases loads when it can.

Vanta v1.6.1 v1.6.1 · v1.6.1-mac · 2026-10-17

  • What's new popup after an update, shown once.
  • Logs viewer: filter as you type, errors and warnings only, match count; Copy log copies the matching lines.
  • Screenshot viewer: full size, arrow keys, copy image (Ctrl+C), show in Explorer/Finder.
  • Server favourites: star servers, favourites first (also on PLAY), sort by players, ping or name, last player count and ping remembered.
  • Preview images on shader and resource pack cards in MODS.

Vanta v1.6.1 for macOS v1.6.1-mac · 2026-10-17

  • Everything in v1.6.1; Show in Finder for screenshots.
  • Intel (macOS 12+), Apple Silicon and universal builds.

Vanta v1.6.0 v1.6.0 · v1.6.0-mac · 2026-10-17

  • Home dashboard: PLAY now opens with Jump back in (your recent instances, with mods, worlds and when you last played), how many friends are online on your network, and What's new from the release notes. It works offline.
  • Modpacks: INSTANCES › Modpacks searches Fabric modpacks on Modrinth, or imports a .mrpack file. Every file is checked against the pack's SHA-512 hash before anything changes. The instance's old mods and config are moved to a vanta-backup-<time> folder first, and your main 1.21.11 instance is never replaced.
  • Export .mrpack: share an instance as a modpack. Mods that are on Modrinth are linked; everything else and your config are bundled.
  • Worlds and backups: INSTANCES › Worlds lists your saves with icons. One-click Back up; Restore never overwrites; Delete always makes a backup first.
  • Update all mods: MODS shows when mods in the selected instance have updates, and Update all installs them, each one hash-checked.
  • Crash helper: the crash card names the mods that were likely involved, can turn a suspect mod off in one click (for added instances), and Copy summary gives you a short text for asking for help.
  • Suggest RAM: INSTANCES › Memory & Java suggests RAM from your PC's memory and the instance's mods and shaders.
  • Appearance: six purple-family accents (Violet, Amethyst, Lavender, Orchid, Indigo, Grape), text size, high contrast and reduce motion, in SETTINGS › Appearance.
  • Ctrl+K quick jump to any tab, setting or action, plus a short welcome tour (you can see it again from SETTINGS).
  • Modrinth downloads now retry up to 3 times and never keep a file that fails its hash check.
  • Accessibility: a skip link, the current tab is announced to screen readers, and focus stays inside dialogs.

Vanta v1.6.0 for macOS v1.6.0-mac · 2026-10-17

  • Everything in v1.6.0, plus the native Mac window from v1.5.2-mac.
  • Intel (macOS 12+), Apple Silicon and universal builds.

Vanta v1.5.2 for macOS v1.5.2-mac · 2026-10-17

  • Vanta now opens in its own native Mac window instead of your web browser. Links to GitHub or Modrinth still open in the browser.
  • Normal Mac menus and shortcuts: Cmd+Q, Cmd+W, copy and paste.
  • Intel (macOS 12+), Apple Silicon and universal builds, as before.

Vanta v1.5.1 for macOS v1.5.1-mac · 2026-10-17

  • Separate Intel (x86_64, macOS 12 Monterey or newer) and Apple Silicon builds, plus a universal zip. All run natively, and Vanta leaves Rosetta if it was started under it.
  • Downloads Temurin Java for your CPU when none is installed. On an Intel Mac Vanta uses only x64 Java and the x64 LWJGL natives. Apple Silicon uses x64 Java under Rosetta for Minecraft before 1.19.
  • Intel defaults: 3–6 GB RAM based on your Mac's memory and G1 GC tuning. On Iris/UHD graphics, new instances start at render distance 8 with Fast graphics, 60 FPS and VSync, and Trailer style (shaders) warns first.

Vanta v1.5.0 v1.5.0 · v1.5.0-mac · 2026-10-16

  • New FRIENDS tab, with no account, email or server: a friend code per install and a friend list stored on your PC.
  • Friends on the same network show online, with their version and world, and Join connects straight to their LAN world.
  • World invites: Vanta turns your e4all address into an invite code. A friend pastes it and joins in one click, and Vanta installs the matching version if needed.

Vanta v1.4.1 v1.4.1 · v1.4.1-mac · 2026-10-13

  • Opening Vanta twice now brings the open window to the front instead of showing a WebView2 error.
  • If WebView2 is still busy, Vanta waits and retries, then says "Vanta is already open".
  • The Vanta Companion mod is only added when Fabric API 0.141.6 or newer is installed.

Vanta v1.4.0 v1.4.0 · v1.4.0-mac · 2026-10-13

  • Skins: Skindex skins download from skindex.pro when you open them (cached and credited); Minecraft's default skins come from your own Minecraft files
  • Fixes "Access is denied" errors when saving settings on Windows
  • More reliable first-launch progress display

Vanta v1.3.1 v1.3.1 · v1.3.1-mac · 2026-10-13

  • Windows download is now 12 MB: Minecraft, mods and the Trailer packs download on first launch from Mojang, Fabric and Modrinth, with a progress bar on PLAY
  • Progress bar when turning Trailer style on
  • Better crash help: catches crashes in the first seconds and explains Fabric "mods are incompatible" errors

Vanta v1.3.0 v1.3.0 · v1.3.0-mac · 2026-10-13

  • Four download types: Vanilla, Fast, Custom (Modrinth picker) and Trailer style
  • INSTANCES tab: Trailer on/off, RAM and Java flags, mod switches, screenshots, Open folder
  • Minecraft-running indicator, live game log and plain-language crash help
  • Update button with hash-checked updates from GitHub
  • Pop-up notifications, keyboard shortcuts, faster startup, and fixes

Vanta v1.2.0 v1.2.0 · v1.2.0-mac · 2026-10-12

  • Downloadable instances 1.18–26.3 with per-version Java
  • BROWSE SERVERS with 20 servers that accept local accounts
  • 3D skin preview
