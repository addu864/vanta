Vanta 1.6.8: PLAY works on Mac again

A fix for Macs: Vanta stopped Minecraft right after PLAY and said it "exited before it stayed alive (exit None)". Update to 1.6.8.

Vanta 1.6.8 is out for Windows and macOS. If you're on a Mac, press Update in Vanta's top bar now.

What went wrong

On a Mac, pressing PLAY showed Minecraft crashed: Minecraft closed unexpectedly with The Java process exited before it stayed alive (exit None). Minecraft hadn't crashed. Right after starting the game, Vanta checks that it is really running. That check read a Linux-only system folder (/proc), which Macs don't have, so on a Mac it always answered "not running" and Vanta stopped the game itself. "exit None" meant the game was still running when Vanta gave up on it.

What 1.6.8 changes

  • Vanta trusts the game process it started, and uses the Mac's own ps tool when it reconnects to a game that is already running.
  • If Java really stops at start-up, the message gives the real exit code, and Show game log starts with the Java path, the CPU and the launch command (no passwords or tokens).
  • The Java runtime Vanta downloads for you is checked to be runnable and has the macOS quarantine flag removed.

Windows wasn't affected, but gets the clearer start-up messages too.
