Vanta for Mac now opens in its own window

Vanta 1.5.2 for macOS runs in a native Mac window with normal menus and shortcuts, and never opens your web browser.

Vanta for macOS now opens in its own native window instead of a browser tab. Normal Mac menus and shortcuts work: Cmd+Q, Cmd+W, copy and paste. Links to GitHub or Modrinth still open in your browser.

There are separate Intel and Apple Silicon builds, plus a universal zip. The Mac builds are unsigned, so the first time, right-click Vanta.app, choose Open, then Open again. They haven't been tested on a real Mac yet; please report problems on GitHub.
