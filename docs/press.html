About Vanta

Vanta is a free Minecraft: Java Edition launcher for Windows and macOS. It plays with local accounts, downloads any version from 1.18 to 26.3, and comes with Fast and Trailer-style mod sets, Modrinth mods and modpacks with every file hash-checked, world backups, a server browser, 3D skin previews, a crash helper and one-click updates. Vanta is fan-made and is not an official Minecraft product.
