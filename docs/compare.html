Download types

Vanilla, Fast, Custom or Trailer style?

When you add a Minecraft version in Vanta (PLAY › Add instance), you pick one of four types. Mods come from Modrinth for that exact version and are hash-checked. Here's how they compare.

Which one should I pick?

Just want to play, fast

Fast

Sodium and friends make the game smoother with no change to how it plays. Works on servers that accept local accounts.

Want it to look amazing

Trailer style

Shaders, 3D-looking textures and smoother animations. Needs a decent GPU; on Intel Macs with only integrated graphics Vanta warns you first.

Have a list of mods in mind

Custom

Search Modrinth for your version and tick what you want. Start from the Fast set so it stays smooth.

Need the unmodded game

Vanilla

Exactly what Mojang ships, for testing, speedrun rules or servers that ask for no mods.

Questions

Which Vanta download type should I pick?

Fast for most players: Fabric with performance mods, so the game runs smoother and plays the same. Trailer style if you want shaders and the cinematic look and have a decent GPU. Custom if you know which mods you want. Vanilla for the unmodded game.

Can I change the type later?

Yes. Add or remove mods in MODS, and turn Trailer style on or off for any Fabric instance in INSTANCES. INSTANCES › Copy mods also moves a setup to another Minecraft version.

Do modded types work on servers?

Fast, Custom and Trailer style add client-side mods, which normally work on servers that accept your account. Some servers have rules about client mods, so check them.
