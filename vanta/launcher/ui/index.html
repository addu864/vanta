PLAY starts Java only when a LOCAL TEST ACCOUNT, a profile, Java, and client.jar are all present. A missing Java or a missing client jar is an error, and launched stays false. The account is not sent to online-mode servers.

A LOCAL TEST ACCOUNT is mode=local and is not valid for online-mode servers.

Microsoft sign-in cannot finish in 0.1 without a client id and an interactive login. Vanta will not invent a session.

Shader presets

          
Shaders are off by default. Vanta Smooth aims at a soft, even grade. Vanta Cinematic aims at deeper shadows. Both are Vanta-owned descriptions with a performance warning, not third-party shader packs. A smooth or cinematic pass can cost frames if a loader ever ran it. If Iris is not installed, the choice is stored and the status stays NOT_APPLIED. Vanta does not claim a shader is running. Not tested in Minecraft. Controller labels are on SETTINGS and were not tested in a game.
